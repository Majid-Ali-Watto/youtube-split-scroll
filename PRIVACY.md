# Privacy Policy

**YouTube Split Scroll: Comments Left & Docked Player**
Last updated: 16 November 2026

## Summary

This extension does not collect, store, transmit or sell any personal data.

## What the extension does

It runs only on `www.youtube.com`. On video pages it rearranges the layout
(moves the comments, changes how the page scrolls, and docks the player, title
and action buttons). All of this happens locally in your browser, on the page
you are already viewing.

## Data

- **Collected:** none. The extension does not read your account, watch history,
  comments or any other content for any purpose beyond positioning page
  elements.
- **Stored:** nothing. It does not use cookies, local storage or any other
  storage.
- **Sent anywhere:** nothing. It makes no network requests, has no analytics
  or tracking, and uses no remote code or third-party services.
- **Permissions:** the extension requests no browser permissions. It only
  injects its script and stylesheet into YouTube watch pages.

## Links

The toolbar popup contains links to the developer's portfolio, GitHub and
LinkedIn. Clicking one opens that site in a new tab, and that site's own
privacy policy applies. The extension itself does not track clicks.

## Changes

If this policy changes, the updated version will be published in this
repository with a new "Last updated" date.
